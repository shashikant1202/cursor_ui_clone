# Cursor UI Clone

A simple website clone of the Cursor AI code editor landing page. This project recreates the look and feel of the official Cursor website using plain HTML and CSS.

##  What's Inside

This is a static website that mimics the Cursor homepage design. It's built with basic web technologies to practice front-end development skills.

##  Project Structure

```
cursor_ui_clone/
├── index.html          # Main HTML file with website structure
├── style.css           # All the styling and layout
├── cursor-fonts/       # Custom fonts used in the design
└── src/                # Images and logos
    ├── General Logos/  # Cursor logo files
    └── site-images/    # Website images
```

##  What's Been Created

###  Header/Navigation Bar
- **Left side**: Cursor logo
- **Center**: Navigation links (Product, Enterprise, Pricing, Resources)
- **Right side**: "Sign In" and "Download" buttons
- Fully styled with proper spacing and hover effects

###  Hero Section
- Main headline: "Built to make you extraordinarily productive, Cursor is the best way to code with AI."
- Download button for Windows
- Clean, centered layout

###  Code Preview Section
- Large preview image of the code editor
- Showcases what the Cursor interface looks like

###  Trusted By Section
- "Trusted every day by teams that build world-class software" heading
- Company logos display (currently using placeholder OpenAI logos)

###  Styling & Design
- Custom fonts (Cursor Gothic and Berkeley Mono)
- Dark theme matching Cursor's brand
- CSS variables for consistent colors and sizing
- Responsive layout structure
- Proper spacing and typography

##  Design Features

- **Color Scheme**: Dark background (#14120b) with light text (#ededed)
- **Custom Fonts**: Includes Cursor Gothic and Berkeley Mono fonts
- **Clean Layout**: Uses flexbox for responsive positioning
- **Brand Consistency**: Matches Cursor's official design language

##  Technologies Used

- HTML5
- CSS3
- Font Awesome icons

##  Current Status

This is a **partial clone** focusing on the top sections of the Cursor homepage:
-  Header and navigation
-  Hero section with CTA
-  Code preview showcase
-  Trusted companies section

##  How to Use

1. Clone this repository
2. Open `index.html` in your web browser
3. That's it! No build process or dependencies needed.
